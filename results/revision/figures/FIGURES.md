# Figures

Generated by `python -m ddiood.paperfigs2 --compile` (locally, or in `colab/experiments/F1_paper_figures.ipynb`). Every main figure is a vector PDF with embedded fonts and a 300 dpi PNG, set in Latin Modern Roman at 90 or 190 mm. One encoding holds across figures: blue `#0072B2` for SemEval-trained encoders, vermilion `#D55E00` for prompted LLMs and label-trained arms, black for the DrugBank lookup and gray `#7F7F7F` for shortcuts; markers are a filled circle (sentence-trained), filled square (mixed-input), open up-triangle (names-trained), open diamond (masked-trained), filled down-triangle (Qwen), open down-triangle (BioMistral), filled black diamond (DrugBank) and open pentagon (H5). The gray band is the equivalence margin (0.40 to 0.60) and appears only on the Mixed-input BiomedBERT Older-clean within-drug row, the H1 primary cell, which alone carries 90% bars; every other interval is 95%. The dashed line is chance in every figure. Decision words appear only on planned or Amendment 7 pre-specified rules on tier A; scores that hold by construction say so. Every number below is filled in by `ddiood/captions.py` from the plotted values, so captions and figures cannot drift apart. Each caption with an OOD number ends with the Commitment 8 sentence.

Assertion layer. `ddiood.paperfigs2` recomputes each plotted value with the `evaluate2` or `amend7_analysis` function that produced the stored value and stops if they differ. The last run made 431 such checks, plus 52 seed-aggregated cell checks inside `ddiood.paperfigs.Data`; the full ledger is in `figure_data_main.json`.

Paths are relative to `results/revision/`; `eval/` is `results/revision/eval/`. Amendment 7 results (E7, E8, E9 and the CPU and post hoc analyses that follow it) are post hoc and exploratory and change no planned decision.

### fig2_signal_map.pdf / .png (superseded main-text draft, now a supplement candidate)

**Caption draft.** Classifiers trained on SemEval sentences read the sentence, not the drugs. AUROC of Sentence-trained, Mixed-input and Names-only BiomedBERT in five conditions:

- the SemEval test sentence;
- the same sentence with both drug mentions replaced by pseudo-words;
- SemEval test pairs given by name only;
- names only for Novel drugs (approved 2020 to 2024, 48 drugs, 438 pairs);
- names only for Older drugs (approved 1985 to 2012, 135 drugs, 1,944 pairs).
