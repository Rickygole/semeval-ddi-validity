# DrugBank lookup reference (tracker E5)

Generated by `scripts/revision_metrics.py` from `artifacts/ood/drugbank_validation.csv` and `drugbank_validation_old.csv`, which `python -m ddiood.pipeline drugbank` writes from a local DrugBank copy (not redistributed). The lookup predicts an interaction when DrugBank lists the pair; unresolvable pairs count as not listed. Labels are tier A (FDA label). The lookup is circular on tier B, which is defined by agreement with DrugBank, so no tier B row is given. AUROC intervals are two-way cluster bootstrap over OOD drugs and partners; MCC and balanced accuracy intervals resample OOD drugs.
